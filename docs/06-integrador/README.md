## Criterios de evaluación

- Coherencia entre las siete áreas y con el proyecto base
- Profundidad y justificación de las decisiones (no solo completar tablas)
- Uso consistente de los artefactos previos
- Calidad del documento: claridad, trazabilidad y presentación
