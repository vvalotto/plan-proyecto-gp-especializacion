# Actividad 4 — Acta de constitución y Plan de gestión del proyecto

**Semana de trabajo:** 25 de noviembre al 1 de diciembre · **Modalidad:** grupal

---

## Objetivo

Autorizar formalmente el proyecto mediante el Acta de Constitución y definir cómo se planificará, ejecutará, monitoreará y cerrará mediante el Plan de Gestión del Proyecto.

## Archivos de esta actividad

| Archivo | Contenido |
|---------|-----------|
| [`acta-constitucion.md`](acta-constitucion.md) | Acta de constitución del proyecto |
| [`plan-gestion.md`](plan-gestion.md) | Plan de gestión, líneas base y principios PMBOK 7 |

## Criterios de evaluación

- El acta define propósito, objetivos medibles, alcance de alto nivel y criterios de éxito
- El plan de gestión es consistente con las actividades 1 a 3 (ciclo de vida, EDT, interesados, RACI)
- Las líneas base (alcance, cronograma, costo) están definidas
- Se explicita cómo se monitorea y controla el proyecto
