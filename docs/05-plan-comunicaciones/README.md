# Actividad 5 — Plan de comunicaciones

**Semana de trabajo:** [A CONFIRMAR en el cronograma de Moodle] · **Modalidad:** grupal

---

## Objetivo

Determinar qué información necesita cada interesado y planificar cómo, cuándo y quién se la comunica durante el proyecto.

## Archivos de esta actividad

| Archivo | Contenido |
|---------|-----------|
| [`necesidades-informacion.md`](necesidades-informacion.md) | Qué necesita saber cada interesado, para qué y con qué detalle |
| [`plan-comunicaciones.md`](plan-comunicaciones.md) | Matriz de comunicaciones, flujo y escalamiento |

## Criterios de evaluación

- Cada interesado del registro (actividad 3) tiene sus necesidades de información identificadas
- Cada necesidad tiene al menos una comunicación planificada, con medio, frecuencia y responsable
- El método (interactivo, push, pull) es adecuado a la audiencia y al contenido
- La frecuencia y el nivel de detalle son coherentes con la matriz de interesados
- El circuito de escalamiento es claro, con plazos y destinatarios
